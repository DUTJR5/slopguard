# Security Policy

## Supported Versions

The latest release on the `main` branch. This project is pre-1.0; only the most recent version receives fixes.

## Reporting a Vulnerability

This tool runs in other people's CI pipelines and parses untrusted package metadata, so we take reports seriously.

Please report vulnerabilities privately:

- Email: dutjasonr.cn.5@gmail.com
- Or use GitHub's private vulnerability reporting on this repository.

Do not open a public issue for security problems.

You can expect an acknowledgement within 72 hours. If the issue is confirmed, we will ship a fix and credit you in the release notes (unless you prefer to stay anonymous).
